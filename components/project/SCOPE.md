# Project BOM — G1 Scope

Chains every built component for one ECI WNS2503 panel (BIO_UF or RO). It covers:
- the load list from ECI's Word file (14);
- feeders: motor current, DOL starter, VFD with protection, control unit, BOP-2, memory card and motor cable (1, 2, 4, 6, 12);
- ECI's own items (13);
- metering on the client's incomer and busbar (15);
- interface relays and I/O terminals (16);
- internal power wiring per feeder (19).

Every open decision is offered as **options**. The main BOM uses the first option; the Excel Options sheet lists what each alternative changes.

Out of scope (owner, 2026-10-11): enclosures, enclosure accessories, heater feeders.
Not yet built: incomer/busbar (8), soft starters (5), short circuit (7), control power/PLC (10), auxiliary switchgear (11), earthing (17).
