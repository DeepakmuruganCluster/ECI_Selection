## 2. What the source says (and does not say)

- Table 12-1 is printed for 30 °C ambient; the guide does not print a conductor temperature for it. The rated conductor temperature only enters through Table 12-2 (60 … 90 °C) or Table 12-4 (heat-resistant types). It must come from the Lapp product page (not held) — so it is an input with no default.
- Single cores bundled in a duct: Lapp's footnote 3 gives 0.67 (3~AC) / 0.76 (1~AC, DC) 'on surfaces' before Table 12-6, whose first row names conduits and wireways. Lapp's 'Attention' note sends single cores in conduits in buildings (methods A1 / B1) to DIN VDE 0298-4 Tables 3 / 5, which are not held. The tool uses the footnote-3 route for panel ducts (R-WIR-05, decision W-1).
- Wires free in air touching each other (not in a duct): footnote 3 sends them to Table 12-8, which is for cable trays — refused.
- No resistance, voltage-drop or short-circuit data are printed: these are not checked.
